시스템 등록자 허용 목록 (failure bucket) …

created_by가 <시스템>@<판> 형식이고 시스템 이름이 이 목록에 있으면 registrant_kind=system으로 분류됩니다. 목록 밖 이름은 거부되지 않고 human + 경고로 처리됩니다. 변경은 즉시(캐시 갱신 후) 반영되며 admin 권한이 필요합니다. 기본값은 config/system_registrants.json, 첫 편집부터 data/system_registrants.json이 우선합니다.
