복구 절차 (화면에서는 복구하지 않습니다) 
0) 검증:   scripts/backup_manager.py verify <세트 ID>
1) 쓰기 중지: docker compose stop api worker
2) DB 복원:   gunzip -c <BACKUP_DIR>/<세트>/db.sql.gz | docker compose exec -T postgres sh -c 'psql -U "$POSTGRES_USER" -d "$POSTGRES_DB" -v ON_ERROR_STOP=1'
3) data 복원(필요 시): tar -xzf <BACKUP_DIR>/<세트>/data.tar.gz -C <repo>
4) 기동:      docker compose up -d api worker
자세한 내용: docs/BACKUP_RESTORE.md (제외 항목: .env, config/auth.json, models, Neo4j)
